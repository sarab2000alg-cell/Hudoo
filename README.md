# هدوء: تطبيق قابل للتثبيت مع إشعارات وأدوار

لا يحتاج أي مكتبة. المطلوب Node.js الإصدار 18 أو أحدث.

## الأدوار
- **المدير:** كل شيء (الحالة، الطلبات، الردود، الاسم، الفريق، الرموز).
- **الأدمن:** الفريق (الدرجات، الأرقام، الحذف) ورمز الانضمام والرمز السري فقط. لا يرى الطلبات ولا يغيّر الحالة.
- **الموظف:** يرى الحالة ويرسل طلباته ويرى ردوده فقط.

## التشغيل للتجربة
    MANAGER_PASSWORD=سر_المدير ADMIN_PASSWORD=سر_الأدمن JOIN_CODE=رمز_الانضمام node server.js
افتح http://localhost:3000 ثم اختر «دخول الإدارة» وأدخل كلمة السر (المدير أو الأدمن يُعرفان من كلمة السر).

## متغيرات البيئة
- MANAGER_PASSWORD: إلزامي.
- ADMIN_PASSWORD: اختياري، وبدونه لا يوجد دخول أدمن.
- JOIN_CODE: رمز انضمام الموظفين (يمكن تغييره لاحقاً من الإعدادات).
- VAPID_SUBJECT: بريد الاتصال بصيغة mailto:you@company.com (تطلبه خدمات الإشعارات).
- DATA_FILE: مسار ملف البيانات. يجب أن يكون على قرص دائم، وإلا ضاعت الاشتراكات والموظفون عند إعادة التشغيل.

## الإشعارات
- يجب أن يعمل الموقع على HTTPS (توفره Render وRailway تلقائياً).
- أندرويد: تعمل من المتصفح مباشرة.
- آيفون (iOS 16.4 فما فوق): يثبّت الموظف التطبيق أولاً (مشاركة ثم إضافة إلى الشاشة الرئيسية) ويفتحه من الأيقونة، ثم يضغط «تفعيل الإشعارات».
- تصل: تغيير الحالة للموظفين، والردود للموظف، والطلبات الجديدة للمدير.

## النشر
انظر شرح Render. الاستضافة المجانية تنام وتمسح الملفات فلا تناسب الإشعارات. استعمل خدمة مدفوعة مع Disk أو خادماً (VPS).
